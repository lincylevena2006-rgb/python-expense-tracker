# 💰 Expense Tracker

A simple command-line Expense Tracker built using Python.

## ✨ Features

- Add expenses
- View all recorded expenses
- Calculate total expenses
- Store expenses permanently in a CSV file
- Simple menu-driven interface
- Input validation

## 🛠️ Technologies Used

- Python
- CSV File Handling

## 📚 Concepts Used

- Functions
- Loops
- Conditional statements
- File handling
- CSV module
- Exception handling
- Lists and dictionaries

## ▶️ How to Run

```bash
python expense_tracker.py
